# The brand: "The Margin"

Chosen by TJ, 11 September 2026, from three options generated by
`scripts/build_brand_assets.py`. The other two — "The Ridge" and "The Orchard" — are
regenerable from that script and are not kept here.

## What it is

Ruled paper, a gutter, one ochre highlighter stroke under the name, a pale treeline along
the bottom edge. The favicon is the same idea reduced to an **L**: a vertical stroke and a
foot drawn as a page margin, with the highlighter mark and two ruled lines beside it.

**It says reading done in public.** TJ, choosing it: *"it seems more formal than the
others"* — and formal is right, because formal is not the same as official. Ruled paper and
a highlighter say this is careful work. A shield or a seal would say this is the town.

## What it deliberately is not

No seal, no crest, no shield, no municipal typography, nothing resembling a letterhead.
This is a private project that reads public documents, and its only authority is that its
figures are checkable. A civic-looking mark would borrow an authority it does not have, and
a resident who believed it would read every finding as the town's own admission.

**And it does not use the brand blue.** `--brand: #12428f` is the Blue Knights' royal — the
DISTRICT's colour. On the site, surrounded by pages that say who wrote them, it reads as
affection for the town; alone on a Facebook banner it reads as the district talking. Of the
three options only "The Ridge" used it, as one small lake far from the wordmark. This one
does not use it at all.

**And it carries no figure.** A banner cannot be corrected, it is seen more than anything
else published here, and a number is stale the day a generator runs. It says what the
project IS, not what it found.

### The logo kit: `logo/`

Built 7 November 2026 by `scripts/build_logo_files.py`, so the favicon and the logo files are
one drawing and cannot drift. Every variant is in light (ink on paper) and `-dark` (paper on
ink); SVGs are resolution-free, and PNGs are in `logo/png/`.

| file | what | PNG sizes |
|---|---|---|
| `mark.svg` | the square mark on its rounded paper tile, the same as the favicon | 16, 32, 48, 64, 128, 180, 192, 256, 512, 1024 px |
| `mark-notile.svg` | the bare L, transparent, for placing on your own surface | 64, 256, 1024 px |
| `logo-horizontal.svg` | the L, then *Lunenburg Budget Project* on one line, transparent | 64, 128, 256, 512 px tall |
| `logo-stacked.svg` | the L, then *Lunenburg* over *Budget Project*, transparent | 64, 128, 256, 512 px tall |
| `*-bg.svg` | either lockup on a paper (or ink) panel with an even inset | as above |
| `favicon.ico` | 16, 32 and 48 in one file, for anything that will not take an SVG | |

180 is the iOS home-screen size and 192/512 are the Android/PWA sizes. The name is Inter Bold
(SIL Open Font Licence) converted to outlines, so the SVGs need no font installed. The
wordmark is all ink, like the cover: **no brand blue**, for the reason above.

**The layout was changed on 11 September so the thumbnail is the mark.** A Facebook GROUP
has no profile picture: the square beside the group's name is the cover's CENTRE SQUARE,
cropped and shrunk to about 56 pixels, and the first layout put the wordmark there, so
the thumbnail read *"nenburg Budget Pro"*. The L-mark now sits in the centre 856x856 with
the wordmark and both addresses stacked beneath it inside the mobile-safe area; the blurb
line was dropped for room (the group description carries it). Option `d` in the
generator; TJ, seeing it: *"OHHH I love that"*.

**1640x856 is the GROUP cover size, checked September 2026** — a PAGE cover is 820x312 and
is a different thing. Facebook crops the top and bottom on mobile and overlays the group
name across the bottom, so everything that matters sits inside the centre 1440x560.

## Changing it

`python3 scripts/build_brand_assets.py` regenerates all three options and the comparison
page at `notes/generated/brand/index.html`. The favicon is referenced from
`fy28/index.html` by a real `<link>` — note that the tag previously carried an INLINE data
URI of the school-building emoji while `favicon.svg` sat unreferenced with a purple
template mark in it, so the file and the tag disagreed about what the icon was. Changing
the file alone changes nothing.
