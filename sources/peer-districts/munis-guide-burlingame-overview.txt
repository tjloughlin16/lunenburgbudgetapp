Navigating the System 
 
Tyler Menu’s Search Feature 
 
If you’re looking for a certain function and/or program – but not sure where it is in the menu – use the Search tool. 
Enter a keyword in the search bar at the top of the Tyler Menu. The system will search the program for you. 
 
1. Click the Search box at the top of the Menu 
2. Type a keyword, such as “account” 
3. Click the search option 
  
 
 
 
Tip:  If you hover the mouse pointer over a program, a 
quick tip will show you the full menu path. 
 
 
 
 
 
 
 
 
Adding a Favorite Tyler Menu Option 
 
It is recommended that you add Favorites to the sidebar (left side of screen) for quick access to Tyler Menu items 
that you use frequently.  This saves you the time of navigating through several levels of menus to find the program 
that you want. 
 
To add a Favorite Menu Option: 
1. Open the Tyler Menu. 
2. Right-click the menu item. 
3. Click Add to My Favorites.

Exporting to Excel 
 
Once you have found a record in MUNIS, for example an account or a purchase order, it is possible to export the 
data to Excel so that you can perform calculations on it.   
 
 
    The Excel option is almost always visible and active in the MUNIS Ribbon.  The exported Excel data may 
contain hyperlinks that you can click to return to that record in MUNIS without searching for it. 
 
Using Tab vs. Mouse-click 
 
For best performance, it is recommended that you use your Tab key to move from field to field in Tyler MUNIS 
screens instead of clicking with the mouse.   This will be practiced during data entry in later classes. 
 
Tab move to the next field 
Shift+Tab move to the previous field

Appendix D – Common Tasks (Search, Browse and Filter) 
 
One of the most common tasks in MUNIS is finding the data that you need, for example, an account, purchase 
order, department or contract.  There is a group of options that work very well together to help you locate 
information.   
 
MUNIS Central programs 
 
The Central programs are the newer version of MUNIS programs for inquiry and reporting, such as Account Central, 
Vendor Central, PO Central, etc.   ALL Central programs start with a SEARCH screen: 
 
Basic Search 
 
Type in a keyword or account segment in the search bar to start the search  
 
    
 
 
 
Advanced Search 
 
Click on Advanced Search to open a pop-up window to select search criteria.  For frequent-use search, save 
the search criteria by clicking Save.  Next time you can go to “My Search” to open your saved search. This save 
time because you don’t have to put in the same search criteria again.

Appendix D – Common Tasks (Search, Browse and Filter) (continued) 
 
Searching within the Search Result 
 
To refine your search, use the header search bar.  Type in an Org Code, a keyword, or even a partial keyword, 
the system will further filter your search result. 
 
Sample:  
Under the Account Central program, we first searched General Fund account by typing in “101”. Then using the header 
search bar, we entered Org Code 101140 [for General Fund (101)/Finance Dept.(140)] to see Finance Department’s 
accounts. Furthermore, typing in 51 under Object Code, we limited the search to show on ly contractual services accounts.

MUNIS traditional programs 
 
In a traditional MUNIS program, click Search and Browse on the ribbons to start a basic search.  You can use the 
Search/Filter Toolbar to filter data within your search result.  Navigation bar will help you navigate between records.

Search/Filter Toolbar 
 
Search/Filter toolbar saves you time when you are viewing a long list.  Search will jump from line to line, 
stopping on each line in the list that meets your criteria.  The Filter option reduces the list to only those 
lines that meet your criteria. 
 
  
 
 
Navigation Bar 
 
Navigation bar is used when there are several records to navigate between, for example, several line 
item records in a requisition, or several requisitions found by a search.
