FY25/FY26 Library Camera Replacement
● The Library security camera system is currently running on two separate systems. Both of 
which are extremely dated and will need to be replaced to avoid an emergent failure.
● The entire project would include 24 cameras: 17 indoor and 7 outdoor.
● Ideally we would like to replace the system all at once but the project can be split into two 
phases as there are two systems.
● Investment Costs:
○ To replace the entire system, the investment would be $81,500
○ To split the project into two phases, the first phase investment would be $36,000 in FY25
○ The second phase investment would roughly $42,000-$48,000 in FY26
○ This recommended system does include cloud licensing. It is offered in 1YR or 3YR increments. We 
recommend 3YR to get the most cost savings. This would be included in the general operating 
budget for IT.

===PAGE 4===
Library Camera Replacement Benefits
● A new system will:
○ offer higher resolution, improved low-light performance, and better overall image quality.
○ allow for better coverage of the facility, inside and out, which will improve security.
○ make it significantly easier to manage and access footage from any secure internet connection. 
○ allow for is scalability. Allowing us to add or remove cameras as needed without significant 
infrastructure changes.
● Currently, there is a lot of time and energy invested in maintaining the existing systems. With 
the new system that would not be necessary as this system reduces the need for on -site 
equipment maintenance and upgrades.

FY25 Town Buildings Security Camera Replacement
● The goal is to have the Town on one ubiquitous security camera system. This capital request 
would fulfill that goal to better align the Town. The buildings included would be the Town 
Hall, Eagle House, the DPW, and the Ritter Building. The Town Hall and Eagle House would 
see replacement of existing equipment as well as new cameras. DPW and the Ritter Building 
would be new installs of equipment.
● The existing systems that are in these buildings are dated, difficult to manage, and lack 
scalability. 
● The benefits mirror the ones listed in the for the Library system replacement.

FY27/FY32 Town Wide Network Infrastructure
● It is recommended to replace network equipment on a (5) year cycle to ensure the 
equipment does not start to degrade and cause disruptions to the network and security of 
the Town. 
● FY27: The replacement of equipment would include the following in Town Hall, PSB, Ritter 
and DPW.
○ Security Appliance (provides protection), 
○ Switches (directs network traffic)
○ Access Points (provides WiFi) 
● FY27: The following equipment would be added to the infrastructure:
○ Eagle House: Firewall, Switches, Access Points
○ Library: Switches
● FY27 Request: $90,000
● FY32: All of the equipment listed above would be replaced with no current plans to expand.
● FY32 Request: $92,000
