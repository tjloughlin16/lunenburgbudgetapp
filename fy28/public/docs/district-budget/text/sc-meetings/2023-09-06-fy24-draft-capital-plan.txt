Lunenburg Primary School (in conjunction with THES)
Access & Security Upgrades 
Project description:
• Installation of upgraded door access controls and alarm keypad.
• Installation of additional security cameras at ALL exterior doors and other areas inside the building 
as well as building mounted cameras for the playground area
 
All school building will be controlled by one system – accessible at each school- this eliminating the 
need for different access cards.
Project cost:  $35,000.00
