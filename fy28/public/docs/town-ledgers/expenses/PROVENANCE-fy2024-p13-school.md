    sources/budget-workbooks/finance-committee/fy26-budget/department-presentations/

## What the report says about itself

Quoted from its first page: `YTD BUDGET REPORT`, `Report generated: 08/07/2024 13:48`,
`Program ID: glytdbud`, `FOR 2024 13`, `ACCOUNTS FOR: 300 SCHOOL DEPARTMENT`. That is the same
MUNIS report as every `glytdbud-expense-*` file in this folder, at period 13.

## Why it is not filed here

Rule 2 of `check_archive_layout.py` says a MUNIS report belongs in the subfolder for what it is,
and this one is an expense report. But it arrived as one file of a 299-file delivery that TJ
chose to keep together, in the committee's own tree, so that its folder still says which
meeting it was presented at. Moving it would break that; copying it would put one document in
two folders, which is the layout check's rule 4. One copy, there, and this note here.

## How it reached us

A records request made to the School Department by a member of the Select Board, whose results
the Finance Committee held, and which the committee's chair passed on in answer to TJ's own
records request. Two removes from the district. See
`sources/budget-workbooks/PROVENANCE-finance-committee.md`.

**Not yet read.** `extract_munis_report.py` has not been pointed at it, so nothing ties it to
its own GRAND TOTAL yet. Until that is done it is a ledger we hold, not a dataset we use.
